# 适用场景与边界

## 它是什么

一个**长期陪伴型**的对话对象：会因为你说了什么而改变情绪，会记着气还没消，会在你安静太久时自己开口。

它不是通用助手——不查资料、不写代码、不做研究。它的目标只有一个：**让"被记住"这件事在聊天里发生**。

---

## 三个能演的完整任务

### 1. 按状态说话

> 你：看看我现在是什么状态，再按状态从库里挑句话

工具链：`get_state` → `pick_line`
产出：一段状态摘要 + 一句贴合当下的话（例如「忙完了吧？这几天我一直在。」）
说明：话不是现编的，是从 129 条库里按时间、沉默、场景筛出来的，**0 次额外模型调用**。

### 2. 让它动手

> 你：帮我打开 QQ

工具链：`open_app`
产出：真的启动（Store 应用走 `shell:AppsFolder`），并**校验进程是否起来**——起不来就如实说，不谎报。

### 3. 整理成一份东西给你

> 你：把最近的哨兵日志整理成一份报告发给我

工具链：`read_logs` → `write_report`
产出：一份 Markdown 报告 + 下载链接。
说明：它会**读真实日志再下结论**，不是复述日志——上面这次它自己看出「A 级每小时该发一条，但日志里全是 skip，两者矛盾」。

---

## 边界

| 能做 | 不能做 |
|---|---|
| 读四个状态文件、两个日志 | 读任意文件、写任意文件 |
| 加/清情绪（按挤占规则） | 绕过规则硬塞第三格 |
| 从话语库挑句 | 无限生成新句子（那是模型模式，要花钱） |
| 打开白名单里的程序 | 打开任意程序、执行任意命令 |
| 交付文件（复制到交付目录） | 对外发送消息、发邮件 |
| 试跑主动搭话（默认不发） | 未经允许真的发出去 |

**安全底线不因情绪改变**：紧急求助与安全相关的问题，即使怒气到 2、疲惫满格，也正常回答。

---

## 失败也要能演

把权限拨到「部分」，再说一次「帮我打开 QQ」：

> 需要您把「完全权限」开关打开，我才能动程序。
> 工具 trace：`open_app → 拒绝：这几个动作需要「完全权限」`

这是有意的——**权限在服务端硬拦，不是把按钮藏起来**。演示时演一次失败，比只演成功更能说明边界是真的。
