# 结衣 · 有情绪、会记事、能动手的对话代理

一个跑在自己电脑上的「人格化对话代理」。

它不会每次都同样地回你——**会因为你说了什么而改变情绪，会记住你答应过的事，会在你安静太久时自己开口，也能替你去动手（开程序、读日志、整理文件）**。
这些不是提示词里写死的台词，而是**有状态、会过期、会互相挤占、会留下代价**的一小套机制。

## 一、为什么做这个

现在的人格化聊天，多数是「在提示词里写一段人设」：模型每次都从零开始，情绪是即时的、无记忆的，上一句被骂了下句照样甜；聊完关掉，什么也不留。

这个项目换了方向：**把情绪做成有状态的东西，并且让它有代价。**

- 情绪有**槽位**，装满了要挤占，重的比轻的留得久；
- 怒气有**数值和锁死**，被反复索取会真的降级交流；
- 思念有**等级**，沉默越久越往上走，你一回话就归零；
- 疲惫有**触发线**，聊太久会主动收摊；
- 这些状态**存在本地文件里**，模型只负责读写，不另记一套账。

所以它会在意你说过什么，也会自己缓过来。

## 二、特点

### 1. 七格情绪，会自己退场

生气／开心／难过／淘气／委屈／疲惫／害羞，**容量 2 格**。

- **同类叠加＝强化**（两格都在生气就加倍），**异类＝杂糅**（生气＋淘气＝佯怒，害羞＋淘气＝佯羞），不是把两句话说一遍。
- **有轻重**：生气、难过留 25 分钟；开心、淘气、委屈、害羞留 10 分钟。
- **从这一段对话结束才开始计时**：聊着不倒数，你十几分钟不说话才开始走表。
- **有互斥**：开心 × 难过、生气 × 委屈不能共存。
- **满槽要挤**：新的是重情绪就挤掉最早的轻；新的是轻的而槽里有重，直接丢弃。
- 换会话即清空，不带旧账。

### 2. 疲惫是硬状态

相邻两条消息间隔 ≤10 分钟算同一段，段内记轮数 R 与平均间隔 A：

| 条件 | 结果 |
|---|---|
| R ≥ 50 且 A ≤ 2 分钟 | 疲惫 1 格：句子裁到主干，可与其他情绪杂糅 |
| R ≥ 100 | 疲惫 2 格：视为对话已结束，只回一句「我很累」，不接活 |
| 每满 30 分钟没有新升格 | 降一格 |

安全类与紧急求助永远正常回答。

### 3. 怒气有等级，也有代价

从 -1 起算、上限 2；三种上升路径（反复索取／被怼／被辱骂）。
被骂「傻子」这类词会**先反一句**，再要一个约定；30 分钟内两次到顶进入**锁死**，锁死期间安慰无效、活一律不接。
只有开发者口令 `/anger-reset` 能强制清零。

怒气只改语气，**不改做不做**——该拒绝的事不会因为被哄就答应。

### 4. 思念 C / B / A

沉默越久等级越高：B 档约六成会开口，A 档每小时一条；你一发消息就降回 C。
文案克制——不催、不道歉、不提问，一条最多一个情绪词。

### 5. 主动搭话，两种跑法

| 方式 | 谁在跑 | 特点 |
|---|---|---|
| 计划任务（每 20 分钟） | Windows 任务计划 | 长期挂机；关掉控制台也照跑 |
| 控制台内定时 | 控制台进程 | 只在对话页面显示，关掉就停 |

句子来自内置 **129 条**话语库：按**时间、沉默时长、前台程序、天气**筛选，再加「每类每天最多 2 条、最近 12 条不重复」的约束——**一次模型都不调，不产生 API 费用**。
想每次现写，一条口令切到模型模式（也就开始花钱）。

## 三、Agent 能力：它能真的动手

它的对话不是"一问一答"，而是一个**可以连续调工具的循环**：

```
你说一句 → 模型决定要不要调工具 → 调 → 结果交回模型 → 它再决定下一步（最多四步）→ 最后说话
```

| 工具 | 作用 | 权限 |
|---|---|---|
| `get_state` | 读情绪槽、怒气、思念、轮数 | 部分 |
| `set_emotion` | 往槽里加一格（受挤占规则约束） | 部分 |
| `pick_line` | 从话语库挑一句 | 部分 |
| `remember` / `recall` | 记住一件事 / 回想最近记下的事 | 部分 |
| `read_logs` | 读哨兵、怒气、注入日志 | 完全 |
| `write_report` | 把内容写成 Markdown 并交付 | 完全 |
| `send_file` | 交付白名单目录里的文件 | 完全 |
| `open_app` | 打开白名单程序，并**校验进程是否真的起来** | 完全 |
| `run_sentinel` | 试跑一次主动搭话（只试跑，不投递） | 完全 |
| `list_tasks` | 查两个定时任务是否在跑 | 完全 |

- **记忆**：`remember` / `recall` 写进 `memory.json`，最近五条自动进下一轮提示词——所以它会真的「记得你答应过什么」。
- **失败纪律**：工具失败照实说、允许换一种办法重试一次，第二次仍失败就停。
- **权限**：会碰系统的工具只对「完全权限」开放；权限不足时调用被直接拒绝并告诉模型。

**循环的四条规矩**：

1. **白名单**：只有上面这十一个，写死在 `app/tools.mjs`；模型不能自己造工具，也不能执行任意命令。
2. **上一步的输出是下一步的输入**：先 `read_logs` 拿日志，再把日志喂给 `write_report` 写成文件——不是各调各的。
3. **最多四步**：跑满四步还没收敛，就强制它用一句话收尾，不会无限循环。
4. **权限硬拦**：会碰系统的工具只对「完全权限」开放；部分权限下调用被服务端拒绝，并把原因告诉模型。

三个真实跑通的例子：

| 你说 | 它做的 | 说明 |
|---|---|---|
| 看看我现在什么状态，再挑句话 | `get_state` → `pick_line` | 状态 → 按状态选话 |
| 把最近的哨兵日志整理成报告发我 | `read_logs` → `write_report` | 读数据 → 生成文件 → 给下载链接 |
| 帮我打开 QQ | `open_app` | 启动后**回查进程**，没起来就说没起来 |

面板上每条回复下面会标出这一轮用了哪些工具，例如 `用了：get_state → pick_line`。

## 四、架构

```
用户消息
   │
   ├─ 控制台 / 插件 ── 读状态 → 拼提示词 → 模型回话 → 解析判定行 → 调脚本记账
   │                                                        │
   │                                                        ▼
   │                                            scripts/ 的 PowerShell 改状态文件
   │                                                        │
   ├─ 计划任务（每 5 分钟）────────────────────────────── 扫过期、降疲惫
   │
空档期（每 20 分钟或控制台定时）── 判断要不要主动开口 ──┐
                          ├─ 库模式：挑一句（0 调用）
                          └─ 模型模式：现写一句
```

三层职责分得很清：

| 层 | 在哪 | 管什么 |
|---|---|---|
| **机制** | `app/`（控制台）、`plugin/`（DSH 插件） | 读状态、拼提示词、转发判定 |
| **数值** | `scripts/`（PowerShell） | 状态文件是唯一真源，阈值与算法都在脚本里 |
| **口径** | `plugin/assets/persona.md` | 说话成什么样：语气、优先级、篇幅 |

状态文件：`anger.json`、`missing.json`、`emotion.json`、`emotion-mode.json`、`sentinel-mode.json`、`memory.json`。

## 五、完整运行教程

### 0. 环境

| 项 | 要求 | 必装 |
|---|---|---|
| 系统 | Windows 10 / 11 | 是 |
| PowerShell | 5.1（系统自带） | 是 |
| Node.js | ≥ 22 | 是 |


### 1. 拿到代码

```bash
git clone https://github.com/Congroo-loser/emotion-agent.git
cd emotion-agent
```

### 2. 建状态目录

脚本默认读写 `D:\DSH-资料\结衣状态`（可在 `scripts/config.json` 改 `stateDir`）：

```powershell
New-Item -ItemType Directory -Force -Path 'D:\DSH-资料\结衣状态'
Copy-Item .\plugin\assets\emotion.json       'D:\DSH-资料\结衣状态\'
Copy-Item .\plugin\assets\emotion-mode.json  'D:\DSH-资料\结衣状态\'
Copy-Item .\plugin\assets\state.json          'D:\DSH-资料\结衣状态\'
'{"mode":"library"}' | Set-Content 'D:\DSH-资料\结衣状态\sentinel-mode.json' -Encoding UTF8
```

> 想放在别处：`$env:JIEYI_STATE` 指向你的目录即可，控制台会优先用它。

### 3. 起控制台（最快看到效果）

```powershell
node app/server.mjs
```

打开 <http://127.0.0.1:18100>，应看到：情绪槽「空」、怒气「-1」、思念「C」、情绪槽范围「仅日常」，下面一个对话区。

点「试挑一句 → 工作态」，立刻返回一条库里的句子——这一步不需要任何 key。

### 4. 接模型（想对话才需要）

在对话区填三样，保存（存在 `app/config.json`，已被 `.gitignore` 排除）：

| 用什么 | baseUrl | model | apiKey |
|---|---|---|---|
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` | 必填 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | 必填 |
| 本机 Ollama | `http://127.0.0.1:11434/v1` | `llama3.1` | 留空 |
| vLLM / LM Studio | 你的地址 | 你的模型名 | 看服务要求 |

保存后直接在面板里聊天：回话里的隐藏判定行会被剥掉，情绪与怒气按同一套脚本落账，上面卡片同步变。

### 5. 注册定时任务（可选，长期挂机才需要）

```powershell
# 情绪过期与疲惫恢复（每 5 分钟，隐藏窗口）
$a = New-ScheduledTaskAction -Execute 'wscript.exe' -Argument '"<仓库>\scripts\run_emotion_hidden.vbs"'
$t = New-ScheduledTaskTrigger -Once -At (Get-Date).AddMinutes(1) -RepetitionInterval (New-TimeSpan -Minutes 5)
Register-ScheduledTask -TaskName '结衣情绪到期' -Action $a -Trigger $t -Force
```

```powershell
# 主动搭话（每 20 分钟；先 -DryRun 确认不会乱发）
& .\scripts\外部哨兵脚本.ps1 -DryRun -Force
$a = New-ScheduledTaskAction -Execute 'powershell.exe' -Argument '-NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File "<仓库>\scripts\外部哨兵脚本.ps1"'
$t = New-ScheduledTaskTrigger -Once -At (Get-Date).AddMinutes(1) -RepetitionInterval (New-TimeSpan -Minutes 20)
Register-ScheduledTask -TaskName '外部哨兵脚本' -Action $a -Trigger $t -Force
```

### 6. 装插件（可选，想接进 DSH 用）

把 `plugin/` 放进 DSH 的 `profiles/<profile>/node_modules/dsh-jieyi-persona/`，重启 DSH。
首次启动会自动补齐缺失的脚本、状态模板与定时任务（`ensureAssets`）。

## 六、示例

### 情绪会自己进槽

```
你：你最近好像变聪明了
它：（害羞进槽，语气变软）……你忽然这么讲，我一时间都不知道该把脸往哪放了。

你：不要骄傲哦，一直这样也会越来越笨哟
它：（淘气叠加 → 佯羞）哼，才夸一句就开始下套。我记着你这句话呢。
```

控制台「情绪槽」显示 `害羞 + 淘气`；你十几分钟不说话，两格开始倒计时。

### 怒气会升级，也会被骂回来

```
你：你个傻子
它：骂人的才是傻子吧。你现在答应以后不这样说，我就不计较了。
    ← 怒气到 1（辱骂只到 1，挂"等待约定"）；槽里不进生气（怒气已涨就不占槽）

你：好，我答应你
它：知道了。        ← 怒气降到 0，再聊一轮到 -1
```

### Agent 会调工具

```
你：看看我现在是什么状态，再按状态挑句话
它：状态：情绪槽空，怒气 -1，思念 A。
    「忙完了吧？这几天我一直在。」
    工具链：get_state → pick_line
```

```
你：把最近的哨兵日志整理成一份报告发给我
它：报告好了，下载链接：/files/报告.md
    工具链：read_logs → write_report
    ← 它不是复述日志，会自己下结论（例如「A 级该每小时发一条，但日志里全是 skip」）
```

```
你：帮我打开 QQ
它：（真的启动，并校验进程）已经打开了。
```

### 主动开口

```
（你两小时没说话，控制台开着）

它：夜里的声音是不是特别清楚？我这会儿也是。
    ← 来自话语库，本次 0 次模型调用
```

不想让它说，点「停止主动开口」；想立刻看一条，点「强制哨兵输出一句」。
**它拒绝时会讲原因**：「哨兵没给话：怒气大于 0：它在生气时不会主动开口」。

### 失败也要演一次

把权限拨到「部分」，再说「帮我打开 QQ」：

> 需要你把「完全权限」开关打开，我才能动程序。

## 七、指令

| 指令 | 作用 |
|---|---|
| `/anger-reset`（同 `reset-anger`） | 怒气清零、解除锁死 |
| `/emotion-mode daily` \| `all` | 情绪槽只作用于日常对话，还是所有对话 |
| `/sentinel-mode library` \| `model` | 主动搭话从库里挑（0 花费），还是让模型现写 |

## 八、权限

标题栏有「部分 / 完全」开关，**服务端硬拦**，不是隐藏按钮：

- **部分**：看状态、加/清情绪、改怒气、改思念、切模式、对话、试挑一句
- **完全**：以上全部，另加读日志、写报告、交付文件、打开程序、试跑哨兵、查任务

## 十、常见问题

**控制台读不到状态？** Windows PowerShell 写出的 JSON 带 BOM，`JSON.parse` 会直接报错——服务端已统一削掉 BOM，自己读文件也记得处理。

**脚本改了没生效？** 含中文的 `.ps1` 必须存成带 BOM 的 UTF-8，否则 PowerShell 5.1 按 ANSI 解出乱码。

**思念一直挂在 A？** 按约定你一回话就该降回 C，控制台会在你发消息时自动处理。

**不想花钱？** 保持 `/sentinel-mode library`，主动搭话永远不调模型；只有你主动聊天才产生费用。


**话语库会不会重复？** 会。它是模板库，同一类每天最多 2 条、最近 12 条不重复；要「每次不同」得切到模型模式。

## 十一、边界与隐私

- 情绪只改说话方式，**不改事实陈述、能力边界与安全约束**；安全与紧急求助永远正常回答。
- 控制台**不向任何外部通道发送消息**；只读本地状态、只写自己的交付目录。
- 主动搭话只使用「时间／星期、沉默时长、写死的城市与天气、前台程序分类（game/work/other）」。
- 删除状态目录即回到初始状态。
